# Day 2: Diabetes Data Analysis Using Python

## 📌 Project Overview
This project focuses on exploring and analyzing the Diabetes dataset using Python in Google Colab. The purpose is to practice data analysis skills, understand dataset structure, and visualize data using charts.

## 🎯 Objectives
- Load and inspect a dataset using Pandas.
- Check missing values and duplicate records.
- Validate data and inspect unusual values.
- Perform Exploratory Data Analysis (EDA).
- Create visualizations using Matplotlib and Seaborn.
- Identify patterns and relationships between variables.

## 🛠️ Tools & Libraries
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## 📂 Dataset
**File:** `diabetes.csv`

The dataset contains information related to diabetes, including variables such as Glucose, BloodPressure, SkinThickness, Insulin, BMI, Age, and Outcome.

## 🔍 Tasks Completed

### 1. Data Loading
Loaded the CSV dataset into a Pandas DataFrame.

### 2. Data Inspection
- Checked the number of rows and columns.
- Reviewed column names and data types.
- Inspected the dataset using `head()`, `info()`, and `describe()`.

### 3. Data Quality Checks
- Checked for missing values.
- Checked for duplicate records.
- Investigated zero values in selected columns.
- Reviewed the `Outcome` categories.

### 4. Exploratory Data Analysis (EDA)
- Examined numerical summaries.
- Explored the distribution of diabetes outcomes.
- Investigated age and glucose distributions.
- Compared BMI across outcome groups.
- Examined correlations between numerical variables.

### 5. Data Visualization
Created charts using Matplotlib and Seaborn:
- Diabetes Outcome Distribution
- Age Distribution
- Glucose Level Distribution
- BMI by Diabetes Outcome
- Correlation Heatmap
